An AI complaint triage system that helps support teams focus on the most urgent cases first.

- ⚡ Uses the **Groq API (LLM)** for real-time sentiment analysis and urgency scoring
- 🎯 Urgency score on a **1–10 scale** and sentiment classes (Positive / Neutral / Negative), with **85% accuracy** on 100+ complaint samples
- ⏱️ Reduced manual triage time by **40%**
- 📊 **Streamlit dashboard** that auto-sorts complaints by urgency

**Tech:** Python · Groq API · NLP · Streamlit

### 📚 Resourcify
A **MERN stack** platform for managing and sharing college academic resources. Deployed on **Vercel** and **Railway**.

- 🔐 **JWT authentication** with role-based access for Student and Staff
- 📁 File upload and download with **MongoDB GridFS**, supporting **150+** PDFs, DOCs and other files
- 🔎 Filtering and search by department, year and category, cutting search time by **30%**
- 👤 Profile management to view, edit details and manage uploads

**Tech:** MongoDB · Express · React.js · Node.js · JWT · GridFS
